# way2AIPM OS v0.31 总 Agent 路由设计规格

## Summary

v0.31 在 `Agent 总控` 中增加第一版总 Agent 路由器：

```text
用户目标
  -> 总 Agent 路由器
  -> 规则化意图识别
  -> 推荐 Review / Preparation / 人工分流
  -> 记录路由建议
  -> 用户点击进入目标模块
```

本版仍然不是完全自主 Agent。总 Agent 只做路由建议和记录，不直接启动子 Agent、不调用模型、不写入缺陷/训练/Brief。

## Goals

- 在 Agent 总控中提供一个目标输入框。
- 根据目标文本推荐现有子 Agent 或人工分流。
- 保存路由记录到 Markdown，便于后续追踪总 Agent 的判断质量。
- 在路由记录中展示推荐 Agent、路由类型、置信度、原因、前置条件和下一步。
- 提供跳转按钮，把用户带到复盘室、Workflow、面试前作战室、作品集或 Agent 总控。

## Non-Goals

- 不让总 Agent 自动启动 `Review Specialist` 或 `Preparation Specialist`。
- 不调用 OpenAI 做意图识别，先用可解释规则。
- 不新增第三个业务 Agent。
- 不绕过人工审批，不改变 LangGraph Runtime 写入边界。
- 不引入 Next.js、数据库或 TypeScript 重构。

## API

新增 `AgentRouterRun` 记录：

```text
content/agent-router-runs/{id}.md
```

新增接口：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| `GET` | `/api/agent-router-runs` | 读取最近的总 Agent 路由记录。 |
| `POST` | `/api/agent-router-runs` | 根据 `intentText` 生成并保存一条路由建议。 |

请求示例：

```json
{
  "intentText": "我想复盘刚才的一面，找出挂点并生成训练任务"
}
```

响应记录包含：

- `selectedAgent`
- `routeType`
- `confidence`
- `targetModule`
- `actionLabel`
- `reason`
- `prerequisites`
- `nextStep`

## Routing Rules

- 命中复盘、挂点、缺陷、训练、修复等词时，推荐 `review_specialist`。
- 命中面试准备、JD、Brief、一面/二面/HR、题目预测等词时，推荐 `preparation_specialist`。
- 命中作品集、公开、发布、脱敏等词时，推荐人工作品集流程。
- 无明显命中时，保持人工分流并提示补充目标。
- 如果缺少复盘或面试轮次，目标模块会指向补数据的入口，而不是假装可直接启动。

## Acceptance Criteria

- Agent 总控可以输入目标并生成路由记录。
- 生成路由记录不会创建 WorkflowRun、AI 分析、缺陷、训练任务或 Brief。
- 记录能在页面中显示，并可点击跳转到目标模块。
- API 只新增路由记录，不调用模型。
- 桌面和窄屏下路由输入、记录卡与原有 Agent 能力卡不溢出。

## Follow-Up

- 后续可统计路由记录是否被用户采纳，用于改进总 Agent 规则。
- 规则稳定后，再考虑将意图识别替换为受控模型调用，并继续保留人工确认边界。
