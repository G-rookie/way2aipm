# way2AIPM OS v0.17 前端交互体验收口规格

## Summary

v0.17 聚焦现有工作台的日常可用性，不新增业务模块，不改变 Markdown 存储结构。

当前 v0.1-v0.16 已经覆盖求职 Pipeline、面试前后、缺陷、训练、表达、项目弹药、作品集、AI 辅助、AI 前沿、节奏运营、总控调度和全局检索。问题不再是“有没有模块”，而是打开之后能不能更快判断今天该做什么、更快进入常用动作、更清楚知道保存或失败状态。

这一版把前端交互从“功能可用”推进到“每天愿意用”。

## Goals

- 总控台增加“今日行动入口”：
  - 快速新增岗位
  - 进入全局检索
  - 新增 AI 分析记录
  - 新增节奏记录
  - 跳转训练计划中心
- 空数据时增加首次使用路径：
  - 引导先创建岗位
  - 提醒后续可从岗位创建面试、Brief、复盘、缺陷和训练
- 统一 Toast 反馈：
  - 成功、错误、提示三类视觉状态
  - API 错误展示为错误状态
  - 操作阻断展示为提示状态
- 增加顶部工作台状态提示：
  - 读取中
  - 今日待办数量
  - Markdown 本地保存
- 表单提交按钮在保存中禁用，避免重复点击。
- README 当前版本更新到 `v0.17`。

## Non-Goals

- 不实现拖拽 Pipeline。
- 不引入前端框架。
- 不接入外部 AI API。
- 不新增数据库。
- 不新增删除能力。
- 不做公开部署。

## UX

### 今日行动入口

展示在总控台顶部指标下方，作为每天打开工作台后的第一组动作。

入口包括：

- 新增岗位
- 全局检索
- 新增 AI 分析
- 记录今日节奏
- 查看训练计划

### 首次使用路径

当还没有岗位机会时，Pipeline 空状态不再只显示空文案，而是展示一个轻量的启动清单：

1. 创建第一个岗位机会
2. 粘贴 JD 或记录来源
3. 收到邀约后创建面试轮次
4. 面试前写 Brief，面试后做复盘
5. 从复盘沉淀缺陷和训练

### Toast 状态

Toast 增加三种类型：

- `success`：保存、生成、同步完成
- `error`：API 或保存失败
- `info`：需要先选择/保存对象等提示

### 顶部状态

顶部显示轻量状态条：

- 当前是否正在读取
- 总控待办数量
- 本地 Markdown 存储状态

## Test Plan

- `node --check public/app.js`
- `node --check server.mjs`
- `git diff --check`
- 空数据时 Pipeline 显示首次使用路径和新增岗位入口。
- 总控台显示今日行动入口，点击后能跳转或创建草稿。
- 保存类操作成功 Toast 为成功状态。
- 阻断类提示 Toast 为提示状态。
- API 错误 Toast 为错误状态。
- 保存中按钮禁用，不允许重复提交。

## Assumptions

- v0.17 主要提升前端交互，不扩展数据模型。
- 后续 v0.18 可以继续做 Pipeline 拖拽、字段 inline edit 或浏览器 E2E。
