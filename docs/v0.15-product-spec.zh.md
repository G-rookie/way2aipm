# way2AIPM OS v0.15 面试前作战室增强规格

## Summary

v0.15 聚焦 `02_面试前作战室`。

当前作战室已经能保存公司调研、JD 拆解、项目映射、问题预测和准备清单，但页面仍然偏长表单。v0.15 要把它升级成更像“作战室”的视图：一眼看出准备是否完整、JD 是否拆清楚、项目证据是否够、风险问题是否有预案。

这一版不新增后端字段，不改变 Markdown 存储结构，只基于现有 Brief 字段做前端作战摘要和准备检查。

## Goals

- 面试前作战室新增“作战态势”摘要区。
- 基于现有字段计算准备完整度：
  - 公司调研
  - 业务与产品理解
  - 产品理解
  - JD 拆解
  - 隐性期待
  - 匹配证据
  - 风险缺口
  - 项目经历映射
  - 高频问题预测
  - 高风险问题
  - 准备清单
- 展示准备清单完成情况：
  - checklist 总数
  - 已完成数量
  - 未完成数量
- 展示作战重点：
  - JD 关键词数量
  - 项目证据条数
  - 高频问题数量
  - 高风险问题数量
- 给出下一步准备建议：
  - 草稿/不完整时提示补齐关键区块
  - 有风险缺口时提示优先补高风险问题
  - 已准备时提示进入面试执行和后续复盘
- README 当前版本更新到 `v0.15`。

## Non-Goals

- 不新增 Brief 字段。
- 不做 AI 自动 JD 拆解。
- 不做外部公司信息抓取。
- 不做日历提醒。
- 不迁移历史 Markdown。
- 不新增删除能力。

## UX

面试前作战室右侧详情区结构：

1. 作战态势
   - 准备完整度
   - 准备清单进度
   - JD / 项目 / 问题 / 风险统计
   - 下一步建议
2. Brief 表单
   - 保持现有字段和保存逻辑
3. 候选项目素材
   - 保持现有可用项目候选展示

完整度标签：

- 已准备
- 待补充

## Test Plan

- `node --check public/app.js`
- `node --check server.mjs`
- 打开面试前作战室，确认有 Brief 时展示作战态势。
- 空 Brief 时仍显示创建入口。
- 填写 JD 拆解、项目映射、问题预测、高风险问题后，确认统计更新。
- 准备清单使用 Markdown checkbox 时，确认完成数和未完成数正确。
- 保存 Brief 后，确认仍写入 `content/pre-interview-briefs/{id}.md`。
- 窄屏下确认作战态势和表单不重叠。

## Assumptions

- 第一版作战态势是基于文本和 checklist 的启发式判断。
- 后续可以在此基础上接入 AI 辅助 JD 拆解、公司调研和题目预测。
