## 本轮交付

- 面试前作战室增加 `Preparation Specialist` Runtime，可按当前面试轮次生成 Brief 建议。
- 模型输入限定为本地岗位 JD、面试轮次信息与可用于面试的项目弹药，不执行外部公司检索。
- 新增 `preparation_brief_v1` 结构化输出，覆盖 JD 拆解、隐性期待、匹配证据、风险缺口、项目映射、问题预测、高风险问题和准备清单。
- LangGraph 使用 `preparation:{interviewRoundId}` 线程在建议生成后暂停，页面逐项决定采纳或保留。
- 审批后才创建或更新 `PreInterviewBrief`；已有 Brief 中未采纳的字段保持不变。

## 已证实边界

- 建议停留在 Runtime checkpoint 等待审批时，Brief Markdown 不新增也不被改写。
- 无现有 Brief 时，审批可以创建唯一草稿 Brief，并仅填入被采纳字段。
- 有现有 Brief 时，选择“保留现有内容”的字段不会被 Agent 建议覆盖。
- 已完成 Runtime 的重复恢复不会再创建第二份 Brief。
- 模型请求临时失败后可以重新启动并恢复到待确认状态。
- `Preparation Specialist` 不拥有删除、公开发布或自动标记完成的能力。
- 使用本地 Playwright 在 `1440 x 1250` 桌面视口与 `390 x 1200` 窄屏视口检查无 Brief 的待审批场景，字段建议、选择控件与操作按钮不存在溢出或遮挡。
