# way2AIPM OS v0.12 OS 结构校准规格

## Summary

v0.12 用来把当前工作台重新校准回最初拟定的 `00-10` OS 框架。

前几个版本为了快速跑通闭环，把“能力缺陷”和“训练任务”放在同一个模块里，也让部分模块编号和最初设计发生了偏移。现在核心能力已经铺齐，需要先把信息架构整理干净，确保后续每个版本都能在稳定的 OS 结构上继续增强。

这一版不改变 Markdown 数据结构，不迁移文件，不新增删除能力，只调整前端导航、模块命名和训练计划中心的独立入口。

## Goals

- 侧边栏模块编号重新对齐原始 OS 框架：
  - `00 总控调度器`
  - `01 求职项目管理中台`
  - `02 面试前作战室`
  - `03 面试后复盘室`
  - `04 项目弹药库`
  - `05 能力缺陷档案`
  - `06 训练计划中心`
  - `07 AI 前沿思维框架`
  - `08 作品集产品线`
  - `09 个人节奏运营官`
  - `10 表达稳定性训练室`
- 保留 `全局检索` 作为辅助入口，但不占用 OS 主编号。
- 保留 `AI 辅助分析` 作为辅助入口，但不占用 OS 主编号。
- 新增独立的训练计划中心页面。
- 训练计划中心复用现有 `content/training-tasks/{id}.md` 数据。
- 能力缺陷档案仍可显示关联训练任务入口，但不再作为训练任务唯一入口。
- README 当前版本更新到 `v0.12`。

## Non-Goals

- 不做训练任务数据迁移。
- 不新增训练任务字段。
- 不引入日历、甘特图或复杂排期。
- 不做批量删除或文件清理。
- 不做数据库迁移。

## UX

侧边栏主结构：

```text
00 总控调度器
01 求职中台
02 面试前作战室
03 面试后复盘室
04 项目弹药库
05 能力缺陷档案
06 训练计划中心
07 AI 前沿思维框架
08 作品集产品线
09 个人节奏运营官
10 表达训练室
AI AI 辅助分析
⌕ 全局检索
```

训练计划中心页面：

- 顶部指标：
  - 训练任务总数
  - 进行中
  - 待验收
  - 已验证
- 左侧：
  - 全局训练任务列表
  - 显示任务标题、所属缺陷、任务状态和验收日期
- 右侧：
  - 任务详情表单
  - 关联缺陷摘要
  - 关联表达训练入口

## Routing Rules

- 从总控调度点击训练任务，进入 `06 训练计划中心`。
- 从全局检索点击训练任务，进入 `06 训练计划中心`。
- 从能力缺陷档案点击训练任务，可以留在缺陷上下文，也可以进入训练计划中心。
- 训练任务仍然通过原有 API 读写，不新增后端接口。

## Test Plan

- `node --check public/app.js`
- `node --check server.mjs`
- 打开侧边栏，确认编号和最初 OS 框架一致。
- 打开训练计划中心，确认空数据和有数据状态都可显示。
- 从总控调度队列点击训练任务，确认跳到训练计划中心。
- 从全局检索点击训练任务，确认跳到训练计划中心。
- 保存训练任务后，确认仍写入 `content/training-tasks/{id}.md`。
- 窄屏下确认训练计划中心表单不溢出。

## Assumptions

- `全局检索` 和 `AI 辅助分析` 是辅助能力，不属于原始 `00-10` 编号序列。
- 第一版训练计划中心先复用现有训练任务表单，后续再增强周计划、验收节奏和训练效果统计。
