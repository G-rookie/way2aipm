# way2AIPM OS Roadmap

## 产品目标

`way2AIPM OS` 是一个面向 AI 产品经理求职与成长的个人工作系统：

```text
岗位机会
  -> 面试准备
  -> 真实面试
  -> 面试复盘
  -> 能力缺陷
  -> 训练任务
  -> 表达稳定
  -> 下一轮验证
```

项目坚持三个原则：

- 先服务个人真实使用，再考虑公开展示。
- AI 只生成可审查建议，重要数据必须人工确认后落库。
- 当前保留 Markdown 本地存储，通过适配层为数据库和新技术栈迁移预留接口。

## 技术决策点

### Markdown 与数据库

当前继续使用 Markdown。只有满足以下情况之一，才推进 SQLite：

- 数据量或关联查询开始影响日常使用。
- 需要趋势分析、复杂筛选或可靠事务。
- 需要跨设备、公开部署或登录。

### Next.js

Next.js 不是 AI 或数据库的前置条件。它在公开页面、服务端渲染、路由和部署成为明确需求时再进入试点。

### AI

AI 的推进顺序固定为：

```text
手动上下文与提示词
  -> 结构化输出契约
  -> 人工采纳闭环
  -> 正式 API 接入
  -> 更广泛的场景扩展
```
