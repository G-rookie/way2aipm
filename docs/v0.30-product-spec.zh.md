# way2AIPM OS v0.30 Agent 总控与运行入口规格

## Summary

v0.30 不新增新的 Agent，而是把已经完成的 Agent / Workflow 能力放到一个统一入口：

```text
Agent 总控台
  -> AI Runtime 配置状态
  -> Review Specialist 能力卡
  -> Preparation Specialist 能力卡
  -> 当前真实编排说明
  -> 跳转到复盘室 / Workflow / 面试前作战室
```

本版目标是让用户能清楚知道：有哪些 Agent、需要什么前置数据、模型配置是否可用、从哪里启动、哪些写入必须人工审批。

## Goals

- 在左侧导航中新增 `Agent 总控`，靠近总控台和 Workflow。
- 显示 AI Runtime 配置状态，只暴露“是否配置”，不暴露 API Key 或模型 ID。
- 展示当前已接入的两个受控 Agent：
  - `Review Specialist`：从面试复盘生成缺陷/训练候选。
  - `Preparation Specialist`：从岗位/JD/项目弹药生成 Brief 建议。
- 展示每个 Agent 的职责、输入、输出、写入边界和当前状态。
- 给出可点击的试用路径：去复盘室、去 Workflow、去面试前作战室、去项目弹药库。
- 明确当前是“受控 Agent + 人工审批 Workflow”，不是完全自主 Agent。

## Non-Goals

- 不新增第三个 Agent。
- 不做总 Agent 自动路由多个子 Agent。
- 不主动调用模型做健康检查，避免无意义 token 消耗。
- 不改变现有 Markdown 存储、AI Runtime checkpoint 或业务写入边界。
- 不引入 Next.js、React、TypeScript 或数据库迁移。

## API

新增只读接口：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| `GET` | `/api/ai-runtime-status` | 返回服务端 AI Runtime 配置状态。 |

响应示例：

```json
{
  "aiRuntime": {
    "provider": "openai",
    "configured": false,
    "apiKeyConfigured": false,
    "modelConfigured": false,
    "customResponsesUrlConfigured": false,
    "langGraphCheckpointConfigured": false,
    "capabilities": {
      "reviewSpecialist": true,
      "preparationSpecialist": true,
      "automaticHealthCheck": false
    }
  }
}
```

约束：

- 不返回 `OPENAI_API_KEY` 明文。
- 不返回 `OPENAI_MODEL` 明文。
- 不主动请求 OpenAI，只检查环境变量是否存在。

## UI Behavior

- `Agent 总控` 顶部展示模型配置、Agent 数量、可启动数量和等待审批数量。
- 配置卡说明 `.env.local` 中需要设置 `OPENAI_API_KEY` 与 `OPENAI_MODEL`，修改后重启服务。
- Agent 能力卡根据当前数据展示状态：
  - 未配置模型：需要模型配置。
  - 没有复盘/面试：缺少数据。
  - 有候选待确认：等待审批。
  - 有可用数据且模型已配置：可启动。
  - 已有 Brief 或完成流程：已有完成记录。
- 编排说明展示两条真实链路：
  - 面试后：Review -> WorkflowRun -> LangGraph Runtime -> 人工审批 -> 缺陷/训练任务。
  - 面试前：InterviewRound -> Preparation Runtime -> 人工审批 -> PreInterviewBrief。

## Acceptance Criteria

- 左侧导航可以进入 `Agent 总控`。
- 未配置 AI 时，页面明确提示需要配置模型，而不是让用户盲点 Agent。
- `/api/ai-runtime-status` 不泄露 API Key 或模型 ID。
- 空数据时，Agent 卡给出下一步入口而不是空白页。
- 已有复盘或面试轮次时，Agent 卡能引导到对应功能页。
- 现有 Workflow Runtime 与 Preparation Runtime 原入口不受影响。
- v0.29 `showcase.html` 公开页不受影响。

## Follow-Up

- `v0.31` 可继续做总 Agent 路由设计：根据用户意图选择 Review、Preparation 或后续新增 Agent。
- Next.js / TypeScript + React 迁移仍建议放在公开展示页或前端重构试点，不应先改动 Agent 后端编排边界。
