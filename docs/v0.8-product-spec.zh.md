# way2AIPM OS v0.8 AI 前沿思维框架规格

## Summary

v0.8 聚焦原始 OS 结构中的 `07_AI前沿思维框架`。

这一版先做一个本地 AI 前沿知识卡工作台，用来沉淀你看到的新模型、新产品、新论文、新行业案例和新产品方法，并把它们转化成面试可用的表达素材。

核心目标不是做新闻阅读器，而是做“认知资产库”：

- 记录前沿主题。
- 总结关键洞察。
- 写清楚和 AI PM 面试的迁移关系。
- 沉淀产品判断框架。
- 提炼可复用的问题和观点。

## Goals

- 补齐 `AI前沿思维框架` 模块，不再只停留在 AI 辅助分析工作台。
- 使用本地 Markdown 存储，保持可读、可迁移。
- 在总控调度器里汇总待消化、待迁移的前沿卡片。
- 和当前作品集、面试、项目弹药体系保持松耦合。

## Non-Goals

- 不接外部新闻 API。
- 不自动抓取网页。
- 不调用外部 AI 自动总结。
- 不做复杂标签图谱。
- 不做删除能力。

## Data Model

保存路径：

```text
content/ai-frontier-cards/{id}.md
```

字段：

- `id`
- `type`
- `topic`
- `category`
- `sourceName`
- `sourceUrl`
- `sourceDate`
- `summary`
- `keyInsights`
- `productImplications`
- `interviewTransfer`
- `portfolioTransfer`
- `openQuestions`
- `tags`
- `status`
- `priority`
- `updatedAt`

枚举：

`category`

- `model_capability`
- `ai_product`
- `agent_workflow`
- `industry_case`
- `research_paper`
- `market_signal`
- `pm_framework`
- `other`

`status`

- `inbox`：刚记录，未消化
- `summarized`：已完成前沿总结
- `mapped`：已完成面试迁移
- `applied`：已用于面试 / 项目 / 作品集
- `archived`：已归档

`priority`

- `low`
- `medium`
- `high`

## UX

新增侧边栏模块：

```text
08 AI 前沿框架
```

页面结构：

- 顶部指标：卡片总数、待消化、已迁移、高优先级。
- 左侧：前沿卡片列表。
- 右侧：卡片详情表单。
- 支持新增卡片。
- 支持编辑主题、来源、摘要、洞察、面试迁移、作品集迁移、开放问题等字段。

## Dashboard Integration

总控调度队列新增来源：

- 高优先级且还未完成迁移的前沿卡片。
- 状态为 `inbox` 的前沿卡片。
- 状态为 `summarized` 但还没有 `interviewTransfer` 的前沿卡片。

点击调度项进入 AI 前沿框架并选中对应卡片。

## API

- `GET /api/ai-frontier-cards`
- `GET /api/ai-frontier-cards/:id`
- `POST /api/ai-frontier-cards`
- `PUT /api/ai-frontier-cards/:id`

第一版不提供删除接口。

## Test Plan

- `node --check server.mjs`
- `node --check public/app.js`
- 创建一张 AI 前沿卡片后，确认生成 Markdown 文件。
- 刷新后，确认卡片能重新读取。
- 修改状态、优先级、迁移说明后，确认 front matter 更新。
- 总控调度队列能显示未消化 / 待迁移前沿卡片。
- 点击总控调度项能进入 AI 前沿框架并选中卡片。

## Assumptions

- v0.8 不做自动研究，只做手动知识沉淀。
- 当前模块与 v0.6 AI 辅助分析互补：v0.6 负责一次性分析工作台，v0.8 负责长期认知资产库。
