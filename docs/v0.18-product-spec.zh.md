# way2AIPM OS v0.18 Pipeline 高频交互增强规格

## Summary

v0.18 聚焦 `01_求职项目管理中台` 的高频交互。

v0.17 已经完成前端体验收口，总控台和首次使用路径已经更顺。v0.18 不继续扩展新模块，而是把 Pipeline 这个最高频入口补到“日常记录够快”的程度：能筛选机会、能在卡片上快速调整阶段/优先级/风险/下一步动作，并且不需要每次都打开完整详情表单。

这一版仍然不改变 Markdown 存储结构。快速编辑通过现有 `PUT /api/opportunities/:id` 更新单个岗位机会。

## Goals

- Pipeline 增加筛选条：
  - 阶段
  - 优先级
  - 风险
  - 是否有下一步动作
  - 是否有未完成面试
- Pipeline 指标根据筛选结果显示：
  - 当前可见机会数
  - 有下一步动作的机会数
  - 高风险机会数
  - 有未完成面试的机会数
- Pipeline 卡片支持快速编辑：
  - 阶段
  - 优先级
  - 风险
  - 下一步动作
- 快速编辑保存后写回对应 Markdown 文件。
- 快速编辑成功/失败使用 v0.17 的 Toast 状态。
- README 当前版本更新到 `v0.18`。

## Non-Goals

- 不实现拖拽 Pipeline。
- 不新增后端接口。
- 不新增数据库。
- 不新增删除能力。
- 不接入外部 AI API。
- 不改变岗位 Markdown front matter 字段。

## UX

### Pipeline 筛选条

位于 Pipeline 看板上方，使用紧凑的筛选控件。

筛选项：

- 阶段：全部 / 各阶段
- 优先级：全部 / high / medium / low
- 风险：全部 / high / medium / low / unknown
- 下一步：全部 / 有下一步 / 无下一步
- 面试：全部 / 有未完成面试 / 暂无未完成面试

### 快速编辑

每张 Pipeline 卡片下方增加轻量快速编辑区：

- 阶段 select
- 优先级 select
- 风险 select
- 下一步 input
- 保存按钮

为了避免卡片点击和表单控件冲突，控件区域点击不触发选择卡片。

### 状态反馈

- 保存中按钮禁用并显示“保存中...”
- 保存成功 Toast：`Pipeline 已更新`
- 保存失败 Toast：错误状态

## Test Plan

- `node --check public/app.js`
- `node --check server.mjs`
- `git diff --check`
- Pipeline 筛选能改变看板可见卡片。
- 清空筛选后看板恢复全部机会。
- 快速修改阶段后，卡片移动到对应列。
- 快速修改优先级/风险后，标签和 Markdown front matter 更新。
- 修改下一步动作后，总控台待办能体现变化。
- 空数据首次使用路径仍可用。

## Assumptions

- v0.18 是进入后端规则层前的最后一轮 Pipeline 前端增强。
- v0.19 开始把跨模块状态联动和调度规则逐步迁到后端服务层。
