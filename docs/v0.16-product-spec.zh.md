# way2AIPM OS v0.16 能力缺陷档案增强规格

## Summary

v0.16 聚焦 `05_能力缺陷档案`。

当前能力缺陷档案已经能记录缺陷标题、类型、证据、描述、严重程度、出现频率、修复状态，并能关联复盘和训练任务。但页面仍偏表单录入。v0.16 要把它升级成更像“缺陷档案”的视图：一眼看出缺陷是否有证据、是否进入训练、是否有表达训练、是否已经形成验证闭环。

这一版不新增后端字段，不改变 Markdown 存储结构，只基于现有字段和关联数据做前端画像、闭环摘要和修复建议。

## Goals

- 能力缺陷详情新增“缺陷画像”摘要区。
- 基于现有字段计算缺陷完整度：
  - 证据
  - 缺陷描述
  - 严重程度
  - 出现频率
  - 关联复盘
  - 训练任务
  - 表达训练
- 展示闭环状态：
  - 证据是否存在
  - 是否关联复盘
  - 是否有训练任务
  - 是否有表达训练
  - 是否已验证或修复
- 展示训练闭环统计：
  - 训练任务数
  - 进行中任务数
  - 待验收任务数
  - 已验证任务数
  - 关联表达训练数
- 给出下一步修复建议：
  - 缺证据时提示补复盘证据
  - 无训练任务时提示创建训练任务
  - 有训练但未验证时提示进入训练计划中心
  - 已修复时提示等待下一轮面试验证
- README 当前版本更新到 `v0.16`。

## Non-Goals

- 不新增缺陷字段。
- 不做自动聚类。
- 不做 AI 自动归因。
- 不做复杂趋势图。
- 不迁移历史 Markdown。
- 不新增删除能力。

## UX

能力缺陷详情区结构：

1. 缺陷画像
   - 档案完整度
   - 闭环状态
   - 训练闭环统计
   - 下一步建议
2. 缺陷表单
   - 保持现有字段和保存逻辑
3. 训练任务和表达训练
   - 保持现有入口，但画像中提供更强提示

完整度标签：

- 已记录
- 待补充

## Test Plan

- `node --check public/app.js`
- `node --check server.mjs`
- 打开能力缺陷档案，确认有缺陷时展示缺陷画像。
- 空缺陷时仍显示空状态。
- 创建缺陷后，确认画像可以显示证据、复盘、训练和表达训练状态。
- 创建训练任务后，确认画像训练统计更新。
- 保存缺陷后，确认仍写入 `content/weaknesses/{id}.md`。
- 窄屏下确认画像和表单不重叠。

## Assumptions

- 第一版缺陷画像基于现有字段和关联数据做启发式判断。
- 后续可以在此基础上做重复问题聚类、缺陷趋势和 AI 辅助归因。
