# way2AIPM OS v0.4 产品规格

## 1. 版本定位

`v0.4` 的主题是：

> 把面试复盘中的问题，转化为可复用的项目弹药和稳定表达。

`v0.3` 已经跑通：

```text
面试后复盘
  -> 能力缺陷
  -> 训练任务
  -> 状态联动
```

`v0.4` 继续补齐“如何把缺陷真正修进表达里”的部分：

```text
能力缺陷 / 高频追问
  -> 项目弹药库
  -> 表达稳定性训练
  -> 可复用回答
  -> 下一轮面试验证
```

这一版的重点不是增加更多记录表单，而是让项目经历和回答表达变成面试中的稳定资产。

## 2. v0.4 目标

### 2.1 核心目标

让用户可以围绕自己的项目经历，沉淀项目故事、关键证据、可量化结果、高频追问和稳定回答，并把它们与能力缺陷、训练任务、面试复盘关联起来。

完成后，用户应该能清楚回答：

- 我的核心项目有哪些？
- 每个项目能证明哪些 AI PM 能力？
- 面试官最可能围绕项目追问什么？
- 每个追问的稳定回答是什么？
- 哪些回答已经训练过，哪些还不稳定？
- 某个能力缺陷应该用哪个项目故事来修复？
- 下一轮面试可以用哪些项目弹药验证改善？

### 2.2 不追求的目标

`v0.4` 仍然不做：

- AI 自动生成项目故事
- 公开作品集页面
- 简历生成
- 语音训练或录音评分
- 大模型模拟面试
- 自动搜索项目资料
- 删除能力

## 3. 范围

### 3.1 本版本包含

- 项目弹药库数据结构
- 项目故事与能力映射
- 项目证据、指标、角色、挑战、结果记录
- 高频追问记录
- 稳定回答版本记录
- 表达训练记录
- 从能力缺陷创建项目表达训练
- 从训练任务关联项目弹药
- 总控台展示待稳定表达
- Markdown 本地存储扩展

### 3.2 本版本暂不包含

- 公开作品集产品线
- AI 自动润色回答
- 多版本回答 diff
- 简历导出
- 音频/视频表达训练
- 面试模拟评分
- 批量导入或批量删除

## 4. 核心用户流程

```text
1. 从已有项目创建项目弹药
2. 填写项目背景、目标、角色、动作、结果和证据
3. 关联该项目能证明的能力
4. 记录围绕该项目的高频追问
5. 为追问写稳定回答
6. 从能力缺陷或训练任务关联项目弹药
7. 创建表达训练记录
8. 标记回答是否稳定
9. 在下一轮面试中验证
```

## 5. 数据模型

### 5.1 ProjectAmmo / 项目弹药

保存路径：

```text
content/project-ammos/{id}.md
```

字段：

- `id`
- `type`: 固定为 `projectAmmo`
- `projectName`
- `projectType`
- `role`
- `period`
- `background`
- `goal`
- `actions`
- `result`
- `metrics`
- `evidence`
- `aiRelevance`
- `pmCompetencies`
- `riskQuestions`
- `linkedWeaknessIds`
- `linkedTrainingTaskIds`
- `status`
- `createdAt`
- `updatedAt`

建议枚举：

#### projectType

- `ai_product`：AI 产品项目
- `data_product`：数据产品项目
- `growth`：增长项目
- `platform`：平台项目
- `operation`：运营项目
- `coursework`：课程 / 练习项目
- `personal`：个人作品项目
- `other`：其他

#### status

- `draft`：草稿
- `usable`：可用于面试
- `needs_deepening`：需要深挖
- `archived`：已归档

### 5.2 FollowUpQuestion / 项目追问

保存路径：

```text
content/follow-up-questions/{id}.md
```

字段：

- `id`
- `type`: 固定为 `followUpQuestion`
- `projectAmmoId`
- `question`
- `questionType`
- `riskLevel`
- `answerDraft`
- `stableAnswer`
- `evidence`
- `status`
- `linkedWeaknessIds`
- `createdAt`
- `updatedAt`

建议枚举：

#### questionType

- `role_depth`：你具体做了什么
- `decision_logic`：为什么这么决策
- `metric_result`：结果和指标
- `tradeoff`：取舍判断
- `failure_reflection`：失败与复盘
- `ai_understanding`：AI 理解
- `business_value`：业务价值
- `other`：其他

#### status

- `unanswered`：未回答
- `drafted`：已有草稿
- `stable`：表达稳定
- `needs_drill`：需要训练

### 5.3 ExpressionDrill / 表达训练

保存路径：

```text
content/expression-drills/{id}.md
```

字段：

- `id`
- `type`: 固定为 `expressionDrill`
- `sourceType`
- `sourceId`
- `question`
- `targetAnswer`
- `practiceRecord`
- `score`
- `status`
- `nextAction`
- `linkedTrainingTaskId`
- `createdAt`
- `updatedAt`

建议枚举：

#### sourceType

- `follow_up_question`：项目追问
- `weakness`：能力缺陷
- `training_task`：训练任务
- `interview_review`：面试复盘

#### score

- `unstable`：不稳定
- `usable`：可用
- `stable`：稳定

#### status

- `todo`：待练
- `practicing`：练习中
- `reviewing`：待复核
- `stable`：已稳定
- `archived`：已归档

## 7. 页面与交互

### 7.1 项目弹药库

新增模块或升级现有预留模块。

页面结构：

- 项目弹药列表
- 项目详情
- 项目追问列表
- 稳定回答编辑区
- 关联缺陷 / 训练任务

交互要求：

- 可以创建项目弹药
- 可以记录项目背景、目标、角色、动作、结果和证据
- 可以为项目添加高频追问
- 可以把追问标记为未回答、已有草稿、表达稳定、需要训练
- 可以从追问创建表达训练

### 7.2 表达稳定性训练

可以作为项目弹药库内的区域，也可以作为独立视图。

页面结构：

- 待训练表达列表
- 表达训练详情
- 目标回答
- 练习记录
- 稳定性评分

交互要求：

- 可以从项目追问、能力缺陷或训练任务创建表达训练
- 可以记录多次练习结果，但 v0.4 第一版只保留一个 `practiceRecord` 字段
- 可以标记回答是否稳定
- 当表达训练标记为 `stable` 时，相关项目追问状态同步为 `stable`

### 7.3 总控台

新增展示：

- 需要深挖的项目弹药
- 需要训练的项目追问
- 表达不稳定的训练项

## 8. API 设计

### 8.1 项目弹药

- `GET /api/project-ammos`
  - 支持查询：`status`、`projectType`

- `GET /api/project-ammos/:id`

- `POST /api/project-ammos`

- `PUT /api/project-ammos/:id`

### 8.2 项目追问

- `GET /api/follow-up-questions`
  - 支持查询：`projectAmmoId`、`status`

- `GET /api/follow-up-questions/:id`

- `POST /api/follow-up-questions`

- `PUT /api/follow-up-questions/:id`

### 8.3 表达训练

- `GET /api/expression-drills`
  - 支持查询：`sourceType`、`sourceId`、`status`

- `GET /api/expression-drills/:id`

- `POST /api/expression-drills`

- `PUT /api/expression-drills/:id`

### 8.4 删除策略

`v0.4` 继续不提供删除接口。

## 9. 状态联动

- 从能力缺陷创建项目弹药时，项目弹药记录追加 `linkedWeaknessIds`
- 从训练任务创建表达训练时，表达训练记录保存 `linkedTrainingTaskId`
- 项目追问状态为 `needs_drill` 时，总控台展示为待训练表达
- 表达训练状态为 `stable` 时，相关项目追问同步为 `stable`
- 项目弹药状态为 `usable` 时，可以作为面试前作战 Brief 的候选素材

## 10. 验收标准

### 10.1 数据验收

- 创建项目弹药后，生成 `content/project-ammos/{id}.md`
- 创建项目追问后，生成 `content/follow-up-questions/{id}.md`
- 创建表达训练后，生成 `content/expression-drills/{id}.md`
- 刷新页面后，项目弹药、追问、表达训练仍能读取
- 不出现删除接口和批量文件操作

### 10.2 流程验收

- 用户能创建项目弹药
- 用户能为项目添加高频追问
- 用户能为追问维护稳定回答
- 用户能从追问创建表达训练
- 用户能标记表达训练是否稳定
- 总控台能看到需要训练的项目追问和表达训练

### 10.3 UI 验收

- 项目、追问、训练之间关系清晰
- 表单可快速记录，不强迫一次填完
- 长文本不溢出、不遮挡
- 窄屏下可以完成核心编辑动作
- 页面保持工作台风格

## 11. 建议实现切片

### Slice 1：项目弹药基础能力

- 新增 `content/project-ammos/`
- 新增 ProjectAmmo API
- 新增项目弹药库视图
- 支持创建、编辑项目弹药

### Slice 2：项目追问基础能力

- 新增 `content/follow-up-questions/`
- 新增 FollowUpQuestion API
- 项目详情中支持追问列表和回答编辑
- 支持追问状态追踪

### Slice 3：表达训练基础能力

- 新增 `content/expression-drills/`
- 新增 ExpressionDrill API
- 支持从追问创建表达训练
- 支持表达稳定性状态追踪

### Slice 4：状态联动与体验补强

- 表达训练稳定后同步追问状态
- 总控台展示待训练表达
- 项目弹药与面试前作战 Brief 建立候选素材关系
- 补充空状态和错误提示

## 12. v0.5 预告

`v0.5` 建议主题：

> 作品集产品线 + 公开展示准备。

它会把项目弹药库中的成熟项目、稳定回答和成长记录，转化为未来可公开展示的作品集素材。
