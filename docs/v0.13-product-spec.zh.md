# way2AIPM OS v0.13 训练计划中心增强规格

## Summary

v0.13 聚焦 `06_训练计划中心`。

v0.12 已经把训练计划中心从能力缺陷档案中独立出来，但它仍然主要是全局任务列表加详情表单。v0.13 要让它更像一个真正的训练运营台：可以快速判断本周要练什么、哪些任务待验收、哪些已经验证、哪些训练已经逾期。

这一版不新增后端 API，不改变 Markdown 存储结构，只在前端基于现有 `content/training-tasks/{id}.md` 数据做更清晰的分组、筛选和验收视图。

## Goals

- 训练计划中心新增视图切换：
  - `总览`
  - `本周`
  - `待验收`
  - `已验证`
- 训练任务列表支持按视图筛选。
- 顶部指标补充逾期、未来 7 天、待验收、已验证。
- 任务列表展示所属缺陷、截止时间状态和任务状态。
- 右侧详情增加训练闭环摘要：
  - 所属缺陷
  - 截止时间状态
  - 任务产物是否填写
  - 验收标准是否填写
  - 验证记录是否填写
- 总控调度和全局检索继续跳转到训练计划中心。
- README 当前版本更新到 `v0.13`。

## Non-Goals

- 不新增训练任务字段。
- 不做日历控件。
- 不做拖拽排期。
- 不做批量操作。
- 不做数据迁移。
- 不做删除能力。

## UX

训练计划中心结构：

- 顶部指标：
  - 训练任务
  - 本周到期
  - 待验收
  - 已验证
- 视图切换：
  - `总览`：展示所有任务。
  - `本周`：展示逾期、今天、未来 7 天到期的任务。
  - `待验收`：展示 `reviewing` 状态任务。
  - `已验证`：展示 `validated` 状态任务。
- 左侧列表：
  - 任务标题
  - 所属缺陷
  - 任务类型
  - 截止时间状态
  - 状态标签
- 右侧详情：
  - 训练任务表单
  - 训练闭环摘要
  - 表达训练入口

## Due Buckets

沿用现有 `dateBucket()` 逻辑：

- `overdue`：已逾期
- `today`：今天
- `soon`：未来 7 天
- `future`：未来更晚
- `none`：未设置截止时间

本周视图包含：

- `overdue`
- `today`
- `soon`

## Test Plan

- `node --check public/app.js`
- `node --check server.mjs`
- 打开训练计划中心，确认视图切换按钮存在。
- 空数据时有清晰提示。
- 创建训练任务后，确认可在总览中看到。
- 设置截止时间为今天或未来 7 天，确认进入本周视图。
- 设置状态为 `reviewing`，确认进入待验收视图。
- 设置状态为 `validated`，确认进入已验证视图。
- 保存训练任务后，确认仍写入 `content/training-tasks/{id}.md`。
- 窄屏下确认视图按钮、列表和详情不重叠。

## Assumptions

- 第一版训练计划增强不做独立周计划文件。
- 当前训练计划的核心对象仍然是训练任务。
- 后续可以在此基础上继续扩展周计划、训练复盘和训练效果趋势。
