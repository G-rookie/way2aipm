## 已证实边界

- 路由 API 会保存一条独立 `AgentRouterRun` 记录。
- 复盘意图会推荐 `Review Specialist`。
- 没有复盘数据时，目标模块指向复盘室补数据，而不是强行启动 Workflow。
- 创建路由记录不会创建 WorkflowRun。
- 测试结束后只删除自身创建的一份路由记录文件。
- 使用本地 Playwright 检查 `1440 x 1280` 桌面视口与 `390 x 1280` 窄屏视口，路由输入框、推荐记录卡、Agent 能力卡与编排说明不存在横向溢出或遮挡。
