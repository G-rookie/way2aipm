# way2AIPM OS v0.10 表达稳定性训练室规格

## Summary

v0.10 聚焦原始 OS 结构中的 `10_表达稳定性训练室`。

之前版本已经有表达训练记录，但它们分散在项目追问、能力缺陷和训练任务内部。v0.10 把表达训练升级为一个独立训练室，用来统一查看所有表达训练，并补充每次练习的 session 记录。

这一版的目标是把“我写过答案”推进到“我能稳定说出口”。

## Goals

- 新增独立侧边栏模块：`10 表达训练室`。
- 汇总所有表达训练记录。
- 为每条表达训练新增练习 session。
- 记录练习时间、练习方式、自评分、卡点、改进回答、稳定性证据和下一步动作。
- 总控调度队列接入待复核 / 未稳定的表达训练与练习记录。

## Non-Goals

- 不做语音录制。
- 不做自动评分。
- 不调用外部 AI。
- 不删除训练记录。
- 不做复杂统计图表。

## Data Model

表达训练仍然保存到：

```text
content/expression-drills/{id}.md
```

新增练习 session 保存到：

```text
content/expression-sessions/{id}.md
```

字段：

- `id`
- `type`
- `drillId`
- `question`
- `practicedAt`
- `attemptType`
- `durationMinutes`
- `selfRating`
- `blockers`
- `improvedAnswer`
- `reviewerNote`
- `stabilityEvidence`
- `nextAction`
- `status`
- `updatedAt`

枚举：

`attemptType`

- `read_aloud`
- `mock_interview`
- `structured_rewrite`
- `fast_recall`
- `review`

`selfRating`

- `unstable`
- `usable`
- `stable`

`status`

- `draft`
- `practiced`
- `needs_rework`
- `stable`
- `archived`

## UX

新增侧边栏模块：

```text
10 表达训练室
```

页面结构：

- 顶部指标：表达训练总数、未稳定训练、练习 session 数、已稳定 session 数。
- 左侧：全局表达训练列表。
- 右侧：选中表达训练的详情、练习 session 列表和 session 表单。
- 支持从选中表达训练创建练习 session。

## Dashboard Integration

总控调度队列增强：

- 未稳定表达训练继续进入总控。
- 状态为 `needs_rework` 的练习 session 进入总控。
- 有 `nextAction` 且未稳定的练习 session 进入总控。

点击表达训练相关调度项进入 `表达训练室` 并选中对应训练。

## API

- `GET /api/expression-sessions`
- `GET /api/expression-sessions/:id`
- `POST /api/expression-sessions`
- `PUT /api/expression-sessions/:id`

第一版不提供删除接口。

## Test Plan

- `node --check server.mjs`
- `node --check public/app.js`
- 创建一个表达训练 session 后，确认生成 Markdown 文件。
- 刷新后，确认 session 能重新读取。
- 修改 session 状态、自评分、下一步动作后，确认 front matter 更新。
- 总控调度队列能显示 needs_rework 或有 nextAction 的 session。
- 点击表达训练调度项能进入表达训练室并选中训练。

## Assumptions

- 表达训练本体继续沿用 `expression-drills`。
- v0.10 只新增练习过程记录，不重构既有项目追问/缺陷/训练任务中的表达训练入口。
