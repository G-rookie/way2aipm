# way2AIPM OS v0.11 全局检索与快速跳转规格

## Summary

v0.11 是原始 `00-10` 模块打通后的第一版横向能力增强。

现在工作台已经覆盖岗位、面试、复盘、缺陷、训练、项目、作品集、AI 前沿、个人节奏和表达训练。随着 Markdown 记录变多，单纯靠模块导航会越来越慢。因此 v0.11 新增一个全局检索入口，用来跨模块查找记录，并一键跳回原始工作区继续编辑。

这一版不新增数据库、不新增后端搜索服务，先基于前端已经加载的本地 Markdown 数据完成快速检索。

## Goals

- 新增侧边栏模块：`全局检索`。
- 支持跨模块检索以下记录：
  - 岗位机会
  - 面试轮次
  - 面试前 Brief
  - 面试复盘
  - 能力缺陷
  - 训练任务
  - 项目弹药
  - 项目追问
  - 表达训练
  - 表达练习记录
  - 作品集项目
  - AI 辅助分析
  - AI 前沿卡片
  - 个人节奏记录
- 支持按内容类型筛选。
- 支持多个关键词检索，空格分隔。
- 结果展示标题、来源模块、更新时间和状态标签。
- 点击结果后跳回对应模块并选中记录。
- 不改变现有 Markdown 存储结构。

## Non-Goals

- 不做全文索引文件。
- 不引入数据库或搜索引擎。
- 不做模糊拼音检索。
- 不做搜索历史记录。
- 不做删除、批量清理或数据迁移。

## UX

新增侧边栏入口：

```text
⌕ 全局检索
```

页面结构：

- 顶部指标：
  - 可检索记录数
  - 当前结果数
  - 筛选范围
  - 当前关键词
- 左侧检索条件：
  - 关键词输入
  - 类型筛选
  - 检索按钮
  - 清空按钮
- 右侧结果列表：
  - 标题
  - 来源模块
  - 更新时间
  - 状态标签
  - 内容摘要

默认不输入关键词时展示最近更新的记录，便于快速回到刚刚处理过的内容。

## Jump Rules

- 岗位机会：跳到求职中台并选中岗位。
- 面试轮次：跳到求职中台并选中轮次。
- 面试前 Brief：跳到面试前作战室并选中对应面试。
- 面试复盘：跳到面试后复盘室并选中对应面试。
- 能力缺陷：跳到缺陷与训练中心并选中缺陷。
- 训练任务：跳到缺陷与训练中心并选中任务。
- 项目弹药：跳到项目弹药库并选中项目。
- 项目追问：跳到项目弹药库并选中追问。
- 表达训练：跳到表达训练室并选中训练。
- 表达练习记录：跳到表达训练室并选中练习。
- 作品集项目：跳到作品集产品线并选中项目。
- AI 辅助分析：跳到 AI 辅助分析模块并选中记录。
- AI 前沿卡片：跳到 AI 前沿思维框架并选中卡片。
- 个人节奏记录：跳到个人节奏运营官并选中记录。

## Test Plan

- `node --check public/app.js`
- `node --check server.mjs`
- 打开全局检索模块，确认默认展示最近记录。
- 输入公司名、项目名、缺陷标题、下一步动作等关键词，确认可以检索到相关记录。
- 切换类型筛选，确认结果范围变化。
- 点击不同类型的结果，确认能跳转到对应模块。
- 窄屏下确认检索条件与结果列表不会互相遮挡。

## Assumptions

- 第一版全局检索只处理已经加载到前端状态里的数据。
- 当前数据规模仍然适合前端内存检索。
- 未来如果 Markdown 文件数量明显增多，再考虑后端索引或 SQLite FTS。
